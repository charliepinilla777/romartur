# Romartur - Joyería y Esmeraldas

Sitio web profesional para Romartur, especializado en:
- Talla de joyas
- Comercio de joyas y esmeraldas
- Cursos de joyería

## Tecnologías

- HTML5
- CSS3 (Variables CSS, Grid, Flexbox)
- JavaScript Vanilla
- Diseño Responsive
- Paleta "Glam Gem Burst" (Dorado, Esmeralda, Rubí, Zafiro)

## Características

- Carrusel de imágenes en hero
- Catálogos por categoría
- Formulario de contacto
- Integración con redes sociales
- Diseño responsive y profesional

## Deployment

Desplegado en Vercel: [romartur.vercel.app](https://romartur.vercel.app)
